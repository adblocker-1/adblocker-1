## 📡 PRTG sensor collection

Ready-to-use custom sensors for [Paessler PRTG](https://www.paessler.com/prtg). They're written in PowerShell, return clean channels and come with sensible limits.

| Area | Project | What it monitors |
|---|---|---|
| 💾 Backup | [**Veeam-backup-PRTG**](https://github.com/adblocker-1/Veeam-backup-PRTG) | Veeam Backup & Replication job status and repository usage |
| 💾 Backup | [**Veeam-Backup365-PRTG**](https://github.com/adblocker-1/Veeam-Backup365-PRTG) | Veeam Backup for Microsoft 365 job status and object counts |
| 💾 Backup | [**Cove-Data-Protection-PRTG**](https://github.com/adblocker-1/Cove-Data-Protection-PRTG) | N-able Cove backup status, errors and backup age |
| 📨 Mail | [**MailStore-PRTG**](https://github.com/adblocker-1/MailStore-PRTG) | MailStore Server archiving profiles and job status |
| 🛡️ Security | [**Sophos-Central-PRTG**](https://github.com/adblocker-1/Sophos-Central-PRTG) | Sophos Central endpoints, servers and mobile devices, with health and alerts |
| ☁️ Cloud | [**entra-Health-Check-PRTG**](https://github.com/adblocker-1/entra-Health-Check-PRTG) | Microsoft Intune and Entra ID device inventory, compliance and sync status |
| 🖥️ Virtualization | [**HyperVReplicaHealth-PRTG**](https://github.com/adblocker-1/HyperVReplicaHealth-PRTG) | Hyper-V replication health per VM (push sensor) |
| 🌐 Network | [**UnifiController-PRTG**](https://github.com/adblocker-1/UnifiController-PRTG) | UniFi Controller devices across platforms, via API key or local login |

- **FreeWave** is a PipeWire mixer with Personal, Stream and Chat mixes, effects and Wave microphone support
